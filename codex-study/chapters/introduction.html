認識 Codex 與使用入口

認識 Chat、Work 與 Codex 的入口，並比較三家編碼代理的模型、方案與價格（2026-10-17 查核）。

Codex 是什麼

Codex 是 OpenAI 推出的程式設計與深度自動化 AI 代理（Agent）。它不僅能讀寫本機程式碼、執行終端機指令與測試，還能操控瀏覽器與桌面軟體、生圖修圖，並直接整合在你的 ChatGPT 帳號中。

Codex 可透過桌面版、CLI、IDE 與雲端入口使用。可選模型依帳號、產品與版本而不同；第 4 章會用本次截圖介紹模型選單，實際清單請以你自己的畫面為準。

Chat、Work 與 Codex：先會選，再看詳細差異

這組截圖的應用程式左上方可切換 ChatGPT 與 Codex；進入 ChatGPT 後可選擇對話或 Work 工作方式。不同版本的入口位置可能調整，請依目前畫面確認。

快速選擇：一般問答用 Chat；要交付文件、試算表或研究成果可選 Work；要看程式差異、處理 Git 專案可選 Codex。Work 與 Codex 的能力有重疊，主要差異是入口、介面與工作呈現；實際權限取決於執行環境與設定。下表供需要進一步比較的人選讀，詳見 OpenAI 官方說明。

1. 核心本質與任務範式解析

  • ChatGPT Chat（日常即時對話）：

    以一般提問、搜尋、潤飾與討論為主。可用工具仍會隨所選模式、外掛與帳號設定變動；若任務要直接修改專案檔案，先確認工作環境與授權。

  • ChatGPT Work（多步驟知識與商業交付助手）：

    適合多步驟的文件、試算表、簡報與研究工作。工作可在本機或雲端的核准環境執行；可存取哪些檔案與工具，取決於目前執行位置、帳號及工作區政策。

  • Codex（軟體工程與本機深度自動化代理）：

    以程式碼專案為核心，可在已授權的工作環境讀寫檔案、執行指令與測試，並搭配工作樹（Worktree）、程式碼審查與 AGENTS.md。實際權限受沙盒、核准政策與執行環境限制。

3. 選讀：三種入口如何配合

以下是一種較大型專案可能採用的流程；一般小任務可以直接在 Codex 專案裡開始，不必逐一切換模式：

  1. 第一步：在 Chat 模式進行架構發想與技術選型

    當你剛接獲一個新需求時，不需要一開始就開專案寫程式。先在 Chat 模式快速詢問：「我想為既有的電商系統加入自動退款風控審核機制，業界常見的架構設計模式與狀態機有哪些？」快速收斂思路並取得架構靈感。

  2. 第二步：在 Work 模式產出規格書（PRD）與驗收清單

    思路清晰後，切換到 Work 模式，掛載產品需求資料夾：「請根據剛才討論的退款風控架構，整合現有 API 規範，產出一份包含 UML 狀態圖、異常邊界處理與資安防禦要求的完整規格書（PRD），並輸出一份驗收測試案例試算表。」由 Work 模式在背景自主交付結構化規格文件。

  3. 第三步：在 Codex 模式掛載程式碼進行編碼、測試與部署

    規格底定後，切換到 Codex 並核對後端專案資料夾：「請讀取已確認的 PRD，在獨立的 Git 工作樹（Worktree）中實作退款風控模組，撰寫測試並回報實際結果；提交或部署前先讓我審閱。」完成後查看差異、測試與產物，再決定下一步。

實用技巧：快速聊天（Quick Chat）與置頂獨立視窗

在 Codex 工作中如果只想臨時問個小問題，可以點擊左上角「新增聊天」旁的「快速聊天」圖示，就能開啟不混入 Codex 專案側邊欄的一般對話。此外，也可以將進行中的聊天彈出為獨立小視窗（Pop out chat）並開啟「最上層顯示（Always on top）」，方便邊看編輯器邊對照。

六大跨平台使用環境

只需登入同一個 ChatGPT 帳號，即可在以下環境切換並共用方案額度：

  • 桌面版應用程式（Windows / macOS）：提供圖形化專案資料夾管理、右側內建瀏覽器與檔案預覽器（Artifacts Viewer）、圖片與網頁標註、Skills 外掛市集與電腦操控。
  • Codex 命令列工具（CLI）：以 Rust 打造的終端機代理（npm install -g @openai/codex），可在終端機目錄內修改程式碼、跑測試與管理工作樹（Worktree）。
  • IDE 擴充功能：支援 VS Code、Cursor、Windsurf、Xcode 與 JetBrains 系列 IDE，在編輯器側邊欄直接呼叫 Codex 並進行行內 Diff 審查。
  • Codex 網頁版與雲端任務（Web / Cloud）：符合使用資格並連結儲存庫後，可在雲端環境執行任務；實際可用性依帳號、工作區與推出進度而定。
  • GitHub 整合：符合使用資格時，可在 Pull Request 使用 Codex 審查功能；先確認儲存庫與授權範圍。
  • iOS / Android 手機 App：若帳號已開通遠端連線（Remote），可連線至保持上線的桌面主機；可用性依帳號與推出進度而定。

Free / Plus 與進階訂閱方案功能差異

不同方案、工作區與推出進度會影響可用功能及額度。以下只列入門時需要核對的方向；價格與詳細權益請以 OpenAI 官方價格與用量頁及自己帳號的「使用量與帳單」為準。截圖中的金額是拍攝當時的帳號畫面。

訂閱方案可用功能範圍（Free 與 Plus 對照）額度與限制說明
Free / Go可先從帳號目前開放的桌面、CLI 或 IDE 入口開始；模型與工具以選單實際顯示為準。留意目前額度與功能是否標示為漸進推出。
Plus可用模型與 Codex 功能較多；仍須按所在產品、工作區與版本核對。在帳號選單查看 5 小時及每週使用量、恢復時間與可用點數。
Pro提供較高用量級距；目前官方頁面有多種 Pro 級距，並非固定只有一種月費。購買前查看當前價格、模型與功能權益。
進階方案想做更多，可以從升級方案開始

Plus 適合每週有幾次專案任務的人；Pro 提供更高的使用額度及不同級距。團隊方案則另有管理與協作功能。想知道自己目前能用哪些模型、雲端功能及剩餘額度，可開啟帳號的「使用量與帳單」；考慮升級時，再查看官方價格與方案頁的最新權益。
