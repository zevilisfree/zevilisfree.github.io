Codex 是什麼

Codex 是 OpenAI 推出的軟體工程與深度自動化 AI 代理（Agent）。它直接整合在你的 ChatGPT 帳號與桌面版應用程式中，不僅能讀寫本機專案程式碼、執行終端機指令與自動化測試、進行 Git 差異審查（Diff Review）與工作樹（Worktree）隔離開發，還能搭配內建瀏覽器、視窗快照（Appshots）、電腦操控（Computer use）與雲端環境完成複雜的多步驟工程任務。

Codex 可透過 Windows / macOS 桌面版、命令列工具（CLI）、IDE 擴充功能、網頁雲端與手機端入口使用。可選模型（如 GPT-6.1 Sol、GPT-6.1 Terra、GPT-6 Astra、GPT-6 Luna）依帳號、產品與版本而不同；第 6 章會結合實拍截圖詳細解析模型選單與推理強度，實際清單請以你自己的畫面為準。

Chat、Work 與 Codex：三種模式的核心差異與協作

在桌面版應用程式中，左上方下拉選單可切換 ChatGPT 與 Codex；進入 ChatGPT 時，可在新對話上方切換「對話（Chat）」或「工作（Work）」。三者可在同一帳號下使用，但不代表共用同一個資料夾、全部對話、工具設定或執行權限。ChatGPT 專案、本機專案、Codex CLI 工作目錄與雲端環境各有自己的資料來源；任務送出前先確認目前環境與可讀取的來源。官方：Projects and chats

快速選擇原則：日常即時問答與腦力激盪用 Chat；要產出結構化文件（Word / PDF）、試算表（Excel）、簡報（PPT）、互動網站（Sites）或多步驟商業研究交付物選 Work；要讀寫程式碼專案、檢視逐行差異（Diff）、操作 Git 工作樹與執行測試則選 Codex。詳見 OpenAI 官方使用指南。

1. 核心本質與任務範式解析

  • ChatGPT Chat（日常即時對話與快速探索）：

    適合快速提問、概念拆解、文案潤飾、即時網路搜尋、語音對話與內建圖片生成與編輯（Image generation）。可隨時掛載已授權的附件與外掛連接器（如 @Google Drive、@Gmail）；當討論成熟想轉為正式產出時，可直接在同一專案切換至 Work 或 Codex。

  • ChatGPT Work（多步驟知識工作與商業成果物交付助手）：

    專為「交付完整成果物（Deliverables）」而設計。Work 不只回傳一段聊天文字，而是能自主規劃多個步驟、跨多個已連結資料夾與雲端外掛蒐集資料，直接生成或修改格式完整的 Word 文件（.docx）、Excel 試算表（.xlsx）、PowerPoint 簡報（.pptx）、PDF 報告、互動網站（Sites）與團隊協作頁（Space / Pages）。在桌面版中，Work 可搭配右側預覽器（Artifacts Viewer）進行母版套用與局部圈選標註（Annotations），也能透過 Work Cloud（搭配本機電腦存取） 在雲端協調並調用本機工具。

  • Codex（軟體工程、程式庫重構與深度自動化代理）：

    以軟體工程與技術專案為核心，提供完整的右側 Git 差異檢視（Review）面板、行內程式碼批註、本機 Git 工作樹（Worktree）平行隔離、AGENTS.md 階層規範、生命週期掛鉤（Hooks）與子代理（Subagents）。實際可讀寫的檔案與網路權限，由你選定的工作區、作業系統原生沙盒（Sandbox）與核准政策（Approval policy）嚴格把關。

3. 實戰演練：把 Chat 的結論交給 Work，再交給 Codex

對於中大型任務，先整理可審閱的結論，再明確提供給下一個模式。每次切換都確認專案、附件、檔案與執行環境；不要假設下一則聊天已讀過前一段對話或本機資料夾：

  1. 第一步：在 Chat 模式快速發想架構與釐清邊界

    先在 Chat 模式討論：「我想為既有的訂單系統加入自動退款風控審核機制，業界常見的狀態機設計與邊界風險有哪些？」收斂後，請 Chat 整理一份可供下一步使用的決策摘要與待確認問題。

  2. 第二步：用 Work 產出可審閱的規格與測試案例

    在 Work 中明確提供剛才的決策摘要、現有 API 規範及授權使用的母版：「請根據附上的資料建立 PRD 與邊界測試案例；缺少依據的條件標記待確認，先交草稿審閱。」開啟實際產物核對內容，再視可用功能於桌面預覽器局部標註。需要團隊共編時，先核對分享範圍。

  3. 第三步：在 Codex 指定可讀的規格來源，規劃與實作

    確認 PRD 與案例表已放在 Codex 目前可存取的工作區，並指定檔案路徑：「先讀取這兩份規格，列出預計修改的模組與測試；待方案確認後實作，完成時回報測試結果與差異。」若使用 Git，可選工作樹隔離變更，再用 Review 面板逐行檢查 Diff；合併或發起 PR 前仍由你確認。

Windows 桌面版必學跨視窗技巧：Mini 與寵物懸浮控制列、支線聊天與 Appshots 快照

在現行三合一整合桌面版中，有三個能大幅減少視窗切換的內建功能（所有快捷鍵皆可於「設定 → 鍵盤快捷鍵」或按下 Ctrl + / 檢視與自訂）：

  • Mini 與寵物懸浮快速聊天（Mini & Pets，輸入 /pet 或預設 Win + Alt + P）：從左下角帳號選單點選「顯示寵物（Alt+Win+P）」、到「設定 → Mini 與寵物」或在對話框輸入 /pet，即可開啟永遠置頂於其他軟體上方的懸浮元件，即時監看背景任務狀態並從下方快速聊天列（Quick Chat）發問。若不想要動畫桌寵角色、只想保留精簡的懸浮輸入列，可在該設定頁選擇 Mini（注意：早期獨立版 ChatGPT App 常見的「設定 → 應用程式」與 Alt + Space 伴侶視窗為舊版架構，現行整合版已改為「Mini 與寵物」、「設定 → 一般 → 彈出式視窗」與「鍵盤快捷鍵」選單）。
  • 區分 ChatGPT 與 Codex 的臨時／旁路對話快捷鍵：
    • 在 ChatGPT 模式下：可點選畫面右上角 + 方框圖示下方的虛線對話氣泡圖示（或按 Ctrl + Shift + N）開啟不留紀錄的臨時對話（Temporary chat），或按 Ctrl + Alt + N 喚出快速聊天（Quick chat）。
    • 在 Codex 模式下：若要開啟不綁定當前專案的獨立對話（Standalone chat）可按 Ctrl + Alt + O（亦可於「設定 → 一般 → 彈出式視窗」設定彈出式視窗快速鍵與預設為獨立對話）；若要在主任務執行中旁路提問而不打斷進度，可點擊畫面右上角的 + 方框圖示、按 Ctrl + Alt + S 或輸入 /side 開啟支線聊天（Side chat）。
  • 同時按下左右兩個 Alt 鍵（Alt + Alt）拍下最上層視窗快照（Appshots）：根據「設定 → Appshots」，預設同時按下兩個 Alt 鍵即可將當前最上層外部軟體的畫面與捲動區外文字層一鍵送入對話（詳見第 7 章）。

六大跨平台使用環境

同一帳號可在多種環境使用 ChatGPT 與 Codex；聊天紀錄、設定、可用工具和本機檔案範圍不一定同步。切換端點時先確認目前可用的專案、來源與權限：

  • 桌面版應用程式（Windows / macOS）：整合 Chat、Work 與 Codex 三合一入口，提供圖形化多資料夾專案管理、右側內建瀏覽器與檔案預覽器（Artifacts Viewer）、圖片與文件局部標註（Annotations）、視窗快照（Appshots）、外掛與技能目錄、電腦操控（Computer use）與桌面寵物（Pets）。
  • Codex 命令列工具（CLI）：以 Rust 打造的高效終端機代理（npm install -g @openai/codex），與桌面版共用 ~/.codex/config.toml 設定檔，支援互動式 TUI 與非互動管線模式（codex exec）、工作樹管理及雲端任務修補套用（codex apply）。
  • IDE 擴充功能：支援 VS Code、Cursor、Windsurf、Xcode 與 JetBrains 系列 IDE，在編輯器側邊欄直接同步活動檔案與選取範圍（/ide-context）、進行行內 Diff 審查，並可將耗時重構委派給 Codex Cloud。
  • Codex 網頁版與雲端任務（Web / Cloud）：符合方案資格（Plus 以上）並連結 GitHub 儲存庫後，可在隔離的雲端容器中平行執行任務、自動跑 Setup Script 與測試，完成後直接建立 Pull Request 或拉回本機。
  • GitHub 線上審查與 Slack / Teams 整合：符合資格時，可在 GitHub PR 留言 @codex review 或 @codex security review 觸發雲端程式碼審查（或開啟自動 PR 審查），亦可於桌面版安裝 Code Review 外掛集中管理 PR 收件匣，或在 Slack / Microsoft Teams 呼叫代理與 Dots。
  • iOS / Android 手機 App：除了直接使用行動版 Chat 與 Work Cloud 外，還可透過 QR Code 配對遠端連線（Remote）至家中或辦公室保持上線的 Windows / Mac 電腦，隨時在手機上發起本機任務、接收推播核准並檢視 Code Diff。

計費提醒ChatGPT 帳號登入 vs. OpenAI API Key 計費的差異

在 Codex CLI 或 CI/CD 自動化管線中，除了使用 ChatGPT 帳號登入（消耗上述訂閱方案配額）外，也可以改綁定獨立的 OpenAI API Key 依 Token 隨用隨付計費。請注意：僅使用 API Key 登入時，屬於純 API 呼叫，不包含 ChatGPT 訂閱附帶的雲端功能（如 Codex Cloud 託管環境、GitHub 自動 PR 審查或 Slack 整合）。

個人方案與月費Free：US$0；Go：US$8；Plus：US$20；Pro：US$100、$200 或 $500／月（Pro $500 獨享 Ultrafast）。可加購 Credits 或走 API 計費。Claude Free（US$0）不含 Claude Code；需訂閱 Pro（US$20／月，年繳折合 $17） 或 Max（US$100 5x／US$200 20x／月） 才能以訂閱額度使用 Claude Code，否則需走 API 計費。Free：US$0／月；目前 Pro／Ultra 價格以所在地結帳頁為準（Google 2026 年 5 月公告曾列 AI Pro US$20／月、AI Ultra US$100 或 $200／月，僅供歷史對照）。
上下文與整合特色上下文視模型與入口而定；獨家整合 Work 商務文件交付、Appshots 視窗快照、內建瀏覽器 Adjust/CDP、Dots/Sites/Space 與免費 Auto-review。Claude 5.5 系列 API 支援最高 1M 上下文；強項在於終端機原生開發流、CLAUDE.md 與深度程式碼推理。Gemini 4 Argon 支援 1M 上下文視窗；強項在於 Google Cloud / Firebase / Android / Workspace 原生生態系整合與多代理協作。
