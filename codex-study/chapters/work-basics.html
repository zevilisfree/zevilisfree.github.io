CHAPTER 02 · 初階（含進階選讀）

ChatGPT Work：委派、交付與驗收

讓 ChatGPT 完成可審閱的文件、分析或重複工作，並清楚分辨資料來源與執行位置。

02
Web／桌面版依 2026-10-25 官方文件查核本章流程尚無實拍截圖

什麼時候改用 Work

Chat 適合一問一答；當任務需要多個來源、多步驟、完整文件或可定期更新的成果時，在 ChatGPT 中切換到 Work。Work 可以規劃、取材、製作檔案，再交回給你審查。它與 Codex 都能處理複雜任務，但 Codex 提供更多程式開發視圖，如 Git 差異與程式碼審查；選擇取決於成果與你要看的細節。官方：Get started with ChatGPT Work、官方：模式選擇

模型選擇補充（2026-10-27）：依官方模型文件，GPT-6.1 Terra 適合日常撰稿、解讀圖片與畫面，以及目標明確的應用程式操作。可在模型選單的 Advanced 中尋找；是否開放依帳號與版本而定。初次練習可請它「閱讀這張圖表，依標籤與數值整理重點；看不清楚的地方請標示不確定」，完成後逐項回查原圖。更完整的模型比較見第 6 章。

第一次練習：把兩段非敏感資料做成比較報告

  1. 準備輸入與完成判準

    建立純練習資料：「方案 A：每月 500 元、提供 20 GB、客服週一至週五；方案 B：每月 650 元、提供 50 GB、客服每日。」不使用真實客戶資料、密碼或未公開合約。

  2. 描述可交付成果

    切到 Work，輸入：「根據下方兩個方案，做一份一頁繁體中文比較報告。包含價格、容量、客服、差異和未提供的資訊；不得補造條款。先給草稿供我審查，再交付檔案。驗收：所有數字要和原文相同，未知欄位標『未提供』。」再貼上練習資料。

  3. 中途引導並核對

    觀察 Work 的進度；如果它把「每日客服」解讀成「24 小時客服」，立刻指出資料只說每日、未說時段。完成後開啟報告，逐項比對 500／650 元、20／50 GB、服務日與未知欄位。若產生檔案，開啟檔案確認內容及版面，別只看聊天摘要。

給 Work 的要求最好含成果、讀者、可用來源、限制、驗收方式與何時停下來給你審查。官方範例也是先指定資料與輸出，再要求標記缺乏證據的主張。官方：Work 的提示方式

檔案與外掛：指定來源，不讓它猜

可直接附上檔案、放在專案來源，或在已安裝且已連線的情況下用 @外掛名稱 指向 Google Drive、郵件、行事曆等工具。安裝外掛不等於已連接帳號；能讀到什麼、能否寫入，取決於外掛設定、連線帳號及來源服務權限。第一次先用測試資料做唯讀查詢，核對它確實取到預期檔案及日期。對外寄信、更新資料庫或分享成果前，檢查收件者、範圍和內容。官方：Plugins

若來源沒有連上，要求 Work 列出它實際讀到的檔案和未能取得的資料；不要讓它依記憶補完。處理商業資料前，先確認組織工作區政策、來源服務權限和資料分享對象。

審閱與修訂文件、表格、簡報和 PDF

指定格式、頁數或欄位、來源與檢查標準。桌面版可在右側預覽支援的文件、簡報、試算表和 PDF；點選內容提出局部修訂，例如「第 2 頁表格的單位改為新臺幣，其他頁保持原樣」。Web 版的預覽與標註能力可能不同，可下載後在相應軟體逐頁、逐表或逐張投影片檢查。「只改選取處」是修訂要求，不是無條件保證；再次對照整份成果和來源。官方：Work with files

驗收清單：檔名及格式正確；內容沒有缺頁、空白表格或錯誤公式；金額與日期有來源；輸出可開啟；對外分享前做一次人工檢查。

分清本機、雲端和跨裝置接力

Web 上的 Work 在受管理雲端環境運作，不會自動讀你電腦上的資料夾或登入中的桌面瀏覽器。桌面版在符合方案與工作區設定時，可選用本機檔案、應用程式或瀏覽器；雲端與本機可用工具、權限及持續執行條件不同。送出前確認任務在哪裡跑、提供了哪些資料與外掛連線。需要本機資源的任務，電腦可能要保持上線；某些跨裝置接力需工作區啟用相應功能。官方：Cloud or local work、官方：跨裝置接力

進階選讀：把已驗證的流程排程

先在一般 Work 聊天把來源、成果格式與失敗時的處理方式測通，再設定每日、每週或事件觸發的排程任務。明確寫出時區、更新頻率、資料來源、何時通知你，以及哪些操作要停下等待審查。Web 排程無法直接使用你電腦的資料夾；桌面版如需本機檔案，電腦與 App 必須維持可用。第一次排程後，查看實際執行紀錄與產物，確認有資料更新再擴大使用。官方：Scheduled tasks

用量、限制與失敗時怎麼做

Work 與 Codex 共用相應的使用量機制；可選模型、點數、速度和額度依方案、工作區與推出進度而變。執行前看帳號的使用量畫面與官方價格與用量頁，不要把範例估算當成固定可發送次數。若任務停在資料權限、網路或工具錯誤，先檢查來源是否存在、連線是否有效、執行環境是否能觸及資料；請 Work 明列未完成的項目，修正後再跑。外部操作與分享應由你審查最後結果。
