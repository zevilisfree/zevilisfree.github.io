技能（Skill）、外掛（Plugin）、模型上下文協定（MCP）與事件掛鉤（Hooks）

先分清楚這四個擴充概念各自負責什麼：

名稱主要作用
技能（Skill）把一項工作的步驟、要求、範本與檢查方法整理成可重複使用的標準流程（透過 $技能名稱 呼叫）。
外掛（Plugin）打包安裝一組完整能力，裡面可以包含技能（Skills）、MCP 連線、瀏覽器擴充功能與事件掛鉤（Hooks）。
模型上下文協定（Model Context Protocol，MCP）讓 Codex 存取已授權的外部工具、資料庫與服務的連接協定（可輸入 /mcp 管理狀態）。
事件掛鉤（Hooks）在 Codex 執行生命週期的特定時間點（例如任務開始前或完成後）自動觸發的本機腳本或檢查指令。

不必為了入門就先學會手動設定 MCP。只要既有外掛能完成任務，就先使用外掛提供的入口。

安裝、呼叫與使用 ChatGPT 登入（Sign in with ChatGPT）

開啟左側「外掛」，在外掛與技能分頁中檢視既有能力（如內建的 Documents、PDF、Spreadsheets、Presentations、Template Creator 與 Codex Security）。需要新增時，搜尋名稱、確認所需權限後再安裝。

安裝之後，有些外掛（Plugin）還需要登入外部帳號（安裝成功不等於帳號已連線）。若服務提供「使用 ChatGPT 登入（Sign in with ChatGPT）」，可依畫面完成連結。呼叫時，可在輸入框用 @外掛名稱 或 $技能名稱 明確指定：

安裝與連線前看權限

外掛（Plugin）、Apps／連接器與模型上下文協定（MCP）工具有各自的存取範圍；本機命令的沙盒與網路限制不會自動套到所有外部工具。安裝前檢查提供者、會讀取的資料、能執行的動作與外部服務；陌生專案的安裝／建置腳本也要先看入口。官方權限說明

可以這樣說
使用已安裝的文件技能，整理我附上的內容。保留原意，不要自行補充未經確認的資訊。

如果系統提示工具無法使用，請依序檢查：是否已安裝並啟用、外部帳號是否已連結、網路能否連線至該項服務。

工作區政策可安裝項目依帳號與管理設定而異

個人帳號可從目前介面查看可用的外掛與技能；Business、Enterprise 與 Edu 工作區還可能由管理員限制第三方外掛和 MCP 伺服器，並提供內部目錄。不要只依方案名稱推定一定能安裝某項工具，應以目前帳號與工作區畫面為準。

把流程做成技能（Skill）

建議先手動完成一遍，確認輸入內容、處理步驟與產出結果都沒問題，再把這個流程整理成技能。不要把一次碰巧成功的操作，直接當成穩定的標準流程。

建立可重複使用的技能（Skill）
使用 $skill-creator，把我們剛才確認過的流程整理成一個可重複使用的技能。
寫清楚需要哪些輸入、依什麼步驟處理、輸出格式與檢查方法。
不要包含帳號、金鑰、個人路徑；遇到缺少資料或需要對外發送時，先停下來向我確認。

產生後，開啟技能說明，重點檢查三件事：有沒有遺漏步驟、有沒有把只適用於這一次的細節寫死、有沒有超出你允許的操作範圍。接著再用一份新的輸入測試一次。

個人技能可供多個專案共用；專案專用技能則應放在對應的專案中。儲存在哪個範圍，決定了它能在哪裡被讀取到。

電腦操控（Computer use）

當任務需要操作你電腦中的軟體或瀏覽器時，先確認帳號所在地區支援，並依提示安裝電腦操控（Computer use）外掛，再到「設定 → Computer use」檢查允許的應用程式與瀏覽器。應用程式核准與檔案／命令沙盒是不同權限：

1. 連接瀏覽器

本次截圖顯示 Chrome 與 Edge 的設定入口；官方擴充功能另列 Brave、Opera、Vivaldi。依目前介面安裝對應擴充功能並核對網站權限。內建瀏覽器（@Browser）與你自己的瀏覽器是不同入口，登入狀態與存取權限也可能不同；請先確認指定的是哪一個分頁。

連接後，可在聊天中指定已開啟的瀏覽器分頁做讀取或操作。每次都先確認分頁網址、登入狀態與預計操作的範圍。

可以這樣說
使用 @Edge 中我指定的這個分頁，讀取頁面並整理摘要。只做讀取，不要送出表單，也不要修改網頁裡的資料。
上傳前檢查

如果網站要求上傳本機檔案，先核對檔案內容、目標網站及擴充功能權限，再決定是否允許。

2. Windows 桌面應用程式操控與安全白名單

電腦操控功能可以看見並操作你允許的應用程式介面。你可以在對話框輸入 @Computer 或 @應用程式名稱 指定目標軟體。在 Windows 上，原生軟體操控會使用目前的桌面並移動滑鼠游標；執行時請保持目標軟體可見，不要同時搶著操作滑鼠。

首次存取應用程式時，依畫面檢查核准要求；「一律允許」會保留後續存取權限，僅在確有持續需要時使用。

先給最小權限範圍

只開啟本次需要的應用程式或網站。處理敏感操作時請在旁確認；任務結束後，可隨時在設定裡撤銷不再需要的授權。

語音對話（Voice）與桌面寵物（Pets）

聽寫會把口述內容轉成輸入框文字，讓你檢查後再送出；語音對話則是開啟通話與任務互動。兩者入口與可用性不同，既有 Codex 任務中的語音功能仍可能按帳號逐步推出。

  • ChatGPT Voice 語音模式：在既有 Codex 任務中點擊語音圖示開啟語音對話，即可直接用口語討論進度、隨時打斷或即時引導，甚至用說的跨任務調度（例如：「幫我切換到正在跑測試的那個任務」）。
  • 桌面寵物（Pets，在對話框輸入 /pet）：讓虛擬寵物（如 Codey）或極簡控制列（Mini）懸浮在桌面最上層。即使主視窗收在背景，也能從寵物狀態（Running 執行中、Needs input 等待核准、Ready 已完成未讀、Blocked 發生錯誤）一眼掌握背景任務，並隨時點擊麥克風或輸入框快速發話。
外接硬體選購說明Codex Micro 實體硬體鍵盤（非軟體訂閱內附功能）

官方文件提到的 Codex Micro 為 Work Louder 推出的獨立實體外接控制器（具備 6 顆多色發光 Agent Keys 與旋鈕，可一鍵切換 6 個平行對話），屬於需要額外購買的硬體配件，一般 Free / Plus 使用者直接使用軟體內建的桌面寵物功能（輸入 /pet）即可獲得完整懸浮監看體驗。
