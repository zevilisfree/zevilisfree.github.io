圖片、視窗快照（Appshots）與網頁回饋

用圖片、視窗快照（Appshots）、局部標註（Annotations）與網頁回饋說清楚修改位置。

生成圖片與加上標註

可以直接在聊天中描述想要什麼圖片，也可以先上傳參考圖。尺寸、用途、風格以及必須保留的內容，儘量一次說清楚。

圖片輸入與圖片生成是不同功能：你可以提供圖片供分析；生成或編輯圖片則依方案可用性與用量而定。官方定價頁目前指出 Free 方案不提供 Codex 圖片生成。

  • 附上圖片：在桌面版或 IDE 擴充功能中，拖曳圖片至輸入框時按住 Shift，或使用可見的附件入口，讓圖片成為聊天上下文；在 CLI 可使用 codex -i screenshot.png。官方圖片輸入說明。
  • 多張參考圖編號法：同時上傳多張圖時，可在提示詞明確指定角色，例如：「圖 1 是要修改的產品圖，圖 2 是配色與光影參考，請保留圖 1 的主體構圖並套用圖 2 的風格」。

圖片產生後，點擊圖片開啟檢視器。需要針對局部區域修改時：

  1. 進入畫布檢視模式，選擇要修改的圖片。
  2. 使用留言或標註工具，點擊需要修改的位置。
  3. 寫清楚「要改成什麼」以及「哪些部分不要動」。
  4. 檢查附上的圖片與標註內容，再依目前介面的提示送出修改要求。

視窗快照（Appshots）：擷取畫面與可取得的文字

當你想讓 Codex 查看另一個軟體的報錯視窗、設定面板、設計稿或文件時，不必手動截圖再存檔上傳！在桌面版介面中，可直接點擊輸入框旁邊的快照按鈕選取目標視窗，即可一鍵拍下 Appshot（應用程式視窗快照）：

  • 同時擷取畫面與捲動區外的文字：Appshot 會拍下目前視窗的可見畫面；若該應用程式提供可讀取的文字，也可能附上畫面外的文字。部分應用程式只能提供截圖，送出前先查看附件內容。
  • 選擇發送目標：依「設定 → Appshots」的目前選項，快照可加入目前聊天或新聊天。發送前先檢查目的地與附帶內容。

網頁註解與開發者工具通訊協定（CDP）

當網頁在右側內建瀏覽器中開啟後，可以直接在頁面上加上註解，不必用長篇文字解釋「左上角第二塊」。

  1. 開啟頁面並進入註解模式

    點擊預覽連結；若目前介面提供網頁註解功能，依畫面提示進入註解模式。如果需要核對其他畫面狀態，請先把頁面切換到該狀態。

  2. 選取元素或區域

    點擊文字、按鈕等元素，或拖曳選取一塊區域。出現選取外框後，確認範圍沒有選得太大。

  3. 使用調整（Adjust）微調樣式並送出意見

    輸入具體的修改方式。需要更細部的樣式回饋時，可點開輸入框旁的「調整（Adjust）」選項，直接調整字型、間距、顏色等設定並即時預覽。儲存註解後，再要求 Codex 處理。

進階除錯：開發者模式（Developer Mode）與 CDP

若遇到複雜的前端錯誤或 API 請求問題，可至「設定 → 瀏覽器（Browser）」開啟 開發者模式（Developer mode / Enable full CDP access）。CDP 是 Chrome 開發者工具通訊協定（Chrome DevTools Protocol）；啟用後 Codex 可依權限讀取 Console 報錯、Network 請求、DOM 結構與效能資料。開啟前先確認網頁及登入資訊是否適合交由工具檢視。

互動視覺化（@Visualize）：把數據與概念變成圖表

當純文字或靜態圖片不足以表達複雜邏輯時，你可以在對話框輸入 @Visualize（從外掛選單選取 Visualize），請 Codex 直接在對話中生成可拖曳滑桿、可調整參數的互動式圖表、演算法模擬器或資料儀表板（若在團隊協作的 ChatGPT Space 頁面中，則可輸入 /visualize 直接嵌入頁面）。

檔案預覽與局部標註（Annotations）

產生文件、圖片或網頁後，點擊回答裡的檔案卡片或連結，即可在右側開啟預覽器（Artifacts Viewer）。右上角的面板按鈕可以切換分割檢視、全螢幕或收起側邊欄。

除了檢視網頁與圖片外，現在右側預覽器還全面支援對 Word 文件（Documents）、PowerPoint 簡報（Presentations）、Excel 試算表（Spreadsheets）、PDF 與 Markdown 程式碼 直接進行局部圈選標註（Annotations）！選取文件中的特定段落、表格或投影片區塊並留下修改意見，Codex 就會只針對圈選處精準修正，保留其餘版面與數據。

檢查結果時，請先確認三件事：

  1. 檔案確實已經儲存，且位置與檔名符合要求。
  2. 開啟後能正常顯示，而不只是看到「已完成」的文字回覆。
  3. 點擊右側差異檢視面板查看受影響的檔案 Diff，再決定是否接受。

網頁只在本機執行時，預覽網址會是本機位址（如 localhost 或 127.0.0.1）。能在自己電腦上開啟，不代表已經公開上線。

修改後再看一遍

樣式預覽不等於檔案已經修改完成。等 Codex 處理完畢後，請重新整理頁面，檢查標註位置與相鄰區域：

  • 圖片：檢查文字、數量、比例，確認有沒有連帶改動到原本已經滿意的部分。
  • 網頁：檢查修改後的一般狀態，再看看小螢幕響應式版面是否仍然完整。
  • 結果不符預期：保留原圖或上一版結果，指出具體差異，再繼續修改。
