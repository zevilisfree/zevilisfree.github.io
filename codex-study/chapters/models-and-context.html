選擇模型與選單結構解析

點擊輸入框右下方的模型名稱（或輸入 /model）。你可以直接選擇官方的「預設（推薦的模型組合）」、手動切換具體的模型世代，或是展開「進階（Advanced）」分別自訂模型、Power 滑桿、推理強度與速度。

下圖是本次帳號拍攝時的「選取模型」選單，包含智慧推薦與多款模型；它不是所有帳號或日後版本的完整清單。模型供應與方案會變動，選擇前請以當前選單及官方模型頁核對：

截圖中的選單列出拍攝當時該帳號可用的模型。官方的模型選擇說明將 Astra 用於高複雜度工作、Sol 用於一般與複雜工程、Luna 用於明確的小任務；實際可用項目、推理強度及額度依產品、版本和方案而定。不要把此圖當成所有帳號固定有八種選擇。

畫面中的模型入門選法
預設不確定時先保留預設，再用結果與實際用量決定是否切換。
Sol 系列一般程式設計、多檔案修改與較複雜的工程任務。
Astra需要較深入分析或複雜視覺理解的任務；先確認帳號是否提供。
Luna 系列範圍清楚、較小的例行工作。

初學者建議：先使用「預設」。只有在任務需要、選單確實提供時才改選具體模型，並查看目前帳號的剩餘用量。

推理強度與速度

推理強度與速度是兩個不同設定；可用檔位依目前模型與帳號而定。

  • 基礎推理強度（Light / Medium / High / Extra High）：決定模型在回答前投入多少思考步驟。複雜任務可以調高，但通常回應較慢、消耗額度也較多。
  • 速度選項：控制服務速度，不等於切換到更聰明的模型。開啟前先看選單顯示的用量提示。
進階選項推理強度與速度依目前模型和方案而定

截圖中的滑桿代表目前帳號提供的選項。調高推理強度通常增加等待時間與用量；快速服務設定則影響回應速度。各檔位、消耗倍率與可用性請以當前介面及官方用量頁為準。

檢視剩餘用量與超額擴充機制

點擊左下角帳號選單，展開「剩餘用量」（或輸入 /usage、/status），即可看到目前可用的額度視窗；也可以到「設定 → 使用情況與計費」檢視詳細紀錄。

  • 依方案查看額度：Plus 與標準 Business 的本機訊息估算以五小時區間呈現，週限制也可能適用；官方定價頁目前指出 Pro 沒有五小時限制。各帳號的實際上限與重設時間，請查看自己的使用量畫面，不要由本頁截圖推算。
  • 跨端點共用額度池：同一個帳號在桌面版、Web Cloud、CLI、IDE 擴充功能與手機端的消耗全部合併計算，並與 ChatGPT Work 共用代理配額池。
  • Plus 與 Pro 方案超額延續方式：符合目前點數購買資格的用戶若在趕專案時耗盡視窗額度，可按需購買個人 ChatGPT Credits（隨用隨付點數） 繼續工作，或於 CLI 切換綁定獨立的 OpenAI API Key 計費。

5 個省用量的實用習慣

  1. 精簡提示詞與輸入素材：只附上與本次修改直接相關的檔案與時間範圍，避免把整份無關歷史紀錄塞入對話。
  2. 明確定義交付規格：事先說清楚目標格式、修改範圍與驗收條件，並將「必要修改」與「加分優化」分開。
  3. 階層化拆分 AGENTS.md：大型專案請將特定子模組的規則放進子資料夾的 AGENTS.md，避免根目錄說明檔過大導致每一輪對話都重複消耗大量上下文 Token。
  4. 關閉暫時不用的 MCP 伺服器：每一個啟用的 MCP 伺服器都會在背景注入工具定義並佔用上下文空間，可輸入 /mcp 檢查並停用閒置連線。
  5. 善用 Luna 處理常規任務：格式整理、提取摘要、簡單轉換等明確任務改選 GPT-6 Luna，實際用量依任務與方案而異。

上下文（Context）壓縮（/compact）

當聊天對話越來越長時，Codex 會自動壓縮上下文，把前面的內容整理成摘要後繼續進行。你也可以隨時在輸入框輸入 /compact 主動觸發壓縮，或輸入 /status 查看目前的上下文使用率。

壓縮的是目前的對話上下文，不是清空用量，也不是重置額度。壓縮過程中請等待它完成即可，不必反覆發送同一句話。需要長期遵守的要求，請寫進自訂指令或 AGENTS.md（第 8 章會詳細說明）。
