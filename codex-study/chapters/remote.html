手機遠端連線（Remote）與雲端任務（Cloud）

配對連接自己的電腦

請在手機安裝最新版的 iOS 或 Android ChatGPT App，並在電腦開啟桌面版應用程式。兩端請登入同一個 ChatGPT 帳號與工作區。

開通條件先確認遠端連線可用

遠端連線的可用性依方案、工作區與推出進度而異。手機與桌面主機需登入相同帳號及工作區，桌面主機須保持上線；若畫面要求額外驗證，請依當前流程完成。詳見 OpenAI 官方遠端連線文件。

  1. 在電腦端開啟遠端連線與保持電腦喚醒

    開啟「設定 →（程式設計）→ 連線 → 控制此電腦」（同頁亦提供「控制其他裝置」與「SSH」分頁），開啟「允許連線」並點擊右上角「新增」。依提示完成驗證，並建議同時開啟下方其他設定的「保持此電腦喚醒」（當電腦接上電源且已啟用遠端存取時，防止進入睡眠）。

  2. 掃描 QR Code 配對手機

    桌面版會顯示一次配對用 QR Code。用自己的手機掃描，讓 ChatGPT App 開啟連線流程；核對帳號與工作區，再完成所要求的驗證。每支手機與每台主機都要個別配對，切勿將配對 QR Code 截圖分享給他人。

  3. 在手機上切換至 Codex 並選擇已配對的電腦

    開啟手機 ChatGPT App，從上方模式選單切換至 Codex，即可在環境標籤列看到「全部」、「☁️ 雲端」與亮綠燈的已連線電腦名稱（如 🟢 💻 Zelda）。點選電腦與專案後，底部輸入欄會顯示「在〈電腦名稱〉上工作」。

從手機發起任務、審批權限與檢視程式碼差異（Code Diff）

選取目標電腦後，你可以繼續進行既有的對話，也可以選擇專案來新增任務。發送要求後，手機會即時同步執行進度與回覆內容；而真正的檔案讀寫與編譯測試仍然是在那台電腦上進行。

  • 遠端權限核准：手機可即時接收並處理等待核准的命令或範圍外讀寫要求；通知與按鈕文案依手機系統、App 版本及通知設定而異。按下允許前，請務必看清具體執行的命令、目標路徑與影響範圍。
  • 手機端檢查結果：可從手機追蹤任務進度與回覆；若目前介面提供程式碼差異（Code Diff），再逐項檢查變更與測試結果。重要變更在正式合併或部署前，仍建議回到桌面版或 Git 儲存庫完整審閱。
  • 需要時使用「代我核准（Approve for me）」：這個模式會啟用 AI 自動審查（Auto-review）。不在座位旁且執行長時間任務時，可依風險選擇第 5 章介紹的核准模式；若某個操作被自動審查攔截，你仍可隨時接手決定，或在對話輸入 /approve 針對單筆被拒操作重試一次。

本機遠端連線（Remote）、Work Cloud 混合協調、Codex 雲端（Cloud）與 SSH

在跨裝置與遠端工作時，系統提供四種不同架構的執行模式。理解「誰負責協調對話」與「程式碼實際在哪一台機器執行」，能幫你避免找不到本機檔案或誤判斷線行為：

環境類型運作方式與檔案存取範圍自己的電腦是否需開機？
1. 本機遠端連線（Remote Control）從手機或網頁直接連回已配對的 Windows / macOS 桌面版 App。所有檔案讀寫、Git 操作與終端機命令都在你的電腦本機執行，完全受本機沙盒與核准規則保護。是（電腦須保持開機喚醒且執行桌面版 App）。
2. Work Cloud × 本機電腦存取（Local Computer Access）由 Work Cloud（雲端工作協調器）負責跨 Web / 手機 / 桌面同步對話狀態，並在需要存取本機檔案或開發工具時，將該步驟委派給已連線的本機電腦執行（詳見下方斷線規則）。存取本機時需開機；若在電腦離線時發起「新的一輪對話」，可降級改用雲端隔離環境（但讀不到本機未推送檔案）。
3. Codex 雲端任務（Codex Cloud）針對已連結 GitHub 的儲存庫，在 OpenAI 託管的雲端隔離容器（Container）中獨立複製專案、修改並執行測試，完成後可直接產生差異或發起 Pull Request（支援輸入 /cloud 切換）。否（全程在 OpenAI 雲端容器執行，電腦關機也不受影響）。
4. 安全殼層遠端主機（SSH Hosts）透過標準安全殼層（Secure Shell，SSH）連線至你自備的遠端開發機、Linux 伺服器或雲端 VM，直接在該遠端主機的工作目錄上進行開發與測試。依目標 SSH 主機而定（目標遠端伺服器須保持連線可用）。

深入理解：Work Cloud 搭配本機電腦存取（Local Computer Access）的斷線與備援規則

根據 官方遠端連線與 Work Cloud 文件，當你使用 Work Cloud 搭配已配對的本機電腦時，請特別留意「回合中斷線」與「新回合離線」的行為差異：

  • 正在執行本機操作的回合中途斷線（Mid-turn disconnect）：如果某個回合已經開始讀寫你的本機檔案或執行本機命令，此時電腦突然休眠或斷網，該回合不會在半途偷偷切換到雲端容器（因為雲端沒有你改到一半的本機狀態），而是會暫停或回報連線中斷，等你恢復電腦連線後再繼續。
  • 電腦離線時發起全新回合（New turn while offline）：如果你的電腦處於關機或離線狀態，而你在手機或網頁上發起新的一輪提問，Work Cloud 可以自動改在雲端隔離環境中回應你的問題或處理雲端連接器資料（但請注意：此時它無法讀取你電腦硬碟裡的本機檔案）。

Codex 雲端環境（Cloud Environments）安全架構：兩階段網路、Secrets 代理與個人金庫

當你使用 Codex Cloud（輸入 /cloud 或在網頁／手機選擇雲端環境）執行任務時，程式碼是在 OpenAI 的雲端隔離容器中運作。根據 官方雲端環境指南，為了兼顧「順利安裝套件」與「防止惡意程式碼外洩機密」，Codex Cloud 採用了極為嚴謹的三層安全設計：

1. 兩階段網路隔離模型（Two-phase Network Security）

  • 第一階段：環境初始化腳本（Setup Script Phase — 預設允許連網）：當雲端容器剛啟動、正在執行你設定的初始化腳本（例如 npm ci、pnpm install、pip install -r requirements.txt）時，容器具備網際網路連線能力，以便從套件庫下載依賴並建立容器快取（Container Caching，大幅加速後續啟動）。
  • 第二階段：代理執行階段（Agent Execution Phase — 預設斷網或白名單限制）：一旦初始化腳本跑完、轉交給 Codex Agent 開始讀寫程式碼與處理任務時，容器會預設關閉外部網際網路存取（Internet Off）！若任務確實需要連網，管理員可精確設定網域白名單（Domain Allowlist）與允許的 HTTP 方法（例如只允許 GET / HEAD），從根本阻斷 Prompt Injection 將原始碼外傳的風險。

2. 環境變數（Environment Variables）vs. 網路機密（Network Secrets）的關鍵差異

在設定雲端環境時，千萬不要把敏感的 API Key 或 Token 放進一般的「環境變數」！請務必區分兩者機制：

  • 一般環境變數（Environment Variables — 明文注入）：以明文形式直接寫入容器環境，Agent 執行 printenv、讀取設定或印出 Log 時都能直接看到真實數值。只適合放非敏感設定（例如 NODE_ENV=test、CI=true）。
  • 網路機密（Network Secrets — 容器內僅有佔位符 + HTTPS Proxy 動態替換）：專為保護敏感金鑰設計！設定為 Network Secret 後，真實金鑰永遠不會進入容器內部——容器裡只會拿到一組無害的虛擬佔位符（Placeholder）。只有當容器內的程式透過 Port 443 HTTPS 代理伺服器（HTTPS Proxy）向你核准的白名單網域發起請求時，外部代理才會在流量出站瞬間將佔位符替換為真實金鑰。就算模型遭到惡意提示詞誘導執行 echo $SECRET_KEY，印出來的也只是佔位符，徹底杜絕金鑰外洩！

3. 個人金庫（Personal Vault）：在團隊共用環境安全掛載個人憑證

如果團隊共用同一個雲端環境設定，但每位工程師在執行任務時需要使用自己的個人開發憑證（例如個人測試帳號 Token 或私有套件讀取權限），請勿寫死在團隊共用設定中。每位成員可前往 「設定（Settings）→ Codex Cloud → 個人金庫（Personal vault）」 儲存個人專屬機密，只有在「你自己發起」的雲端任務中才會安全掛載。

連線與安全最佳實踐

使用本機遠端連線（Remote）時，電腦必須保持開機連線、喚醒狀態，並持續執行桌面版應用程式。如果找不到入口或無法連線，請先將手機與電腦兩端更新至最新版本、核對帳號與工作區，並檢查電腦是否進入休眠。

若遠端任務還要操作 Windows 桌面視窗（電腦操控，Computer use），工作階段需保持螢幕解鎖、連接網路，且目標應用程式可見；單純保持電腦開機但鎖定螢幕，無法完成桌面 GUI 操控。詳見 官方電腦操控文件。

請只連接自己信任的個人裝置。不再使用時，隨時可在電腦的「設定 → 連線 → 控制此電腦」中點擊裝置旁的「撤銷存取權」解除配對；切勿將配對 QR Code、裝置資訊或核准畫面中的敏感內容公開分享。

手機只是操作入口：從手機連回自己的電腦，不會自行擴大那台電腦可用的檔案或工具權限。雲端任務（Cloud）則在另一個隔離容器執行，能使用哪些儲存庫、網路白名單與 Network Secrets，請在雲端環境設定中逐項確認，不要以本機的核准選單推定雲端權限。
