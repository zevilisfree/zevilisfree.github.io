手機遠端連線（Remote）與雲端任務（Cloud）

從手機連接保持上線的電腦，區分遠端連線（Remote）、雲端任務（Cloud）與 SSH 主機。

配對連接自己的電腦

請在手機安裝最新版的 iOS 或 Android ChatGPT App，並在電腦開啟桌面版應用程式。兩端請登入同一個 ChatGPT 帳號與工作區。

開通條件先確認遠端連線可用

遠端連線的可用性依方案、工作區與推出進度而異。手機與桌面主機需登入相同帳號及工作區，桌面主機須保持上線；若畫面要求額外驗證，請依當前流程完成。詳見 OpenAI 官方遠端連線文件。

  1. 在電腦端開啟遠端連線

    開啟「設定 → 連線（Connections）→ 控制此 Mac 或 PC（Control this Mac or PC）」，選擇設定（Set up）或新增（Add）。依提示允許遠端存取，並完成帳號或工作區要求的驗證。

  2. 掃描 QR Code 配對手機

    桌面版會顯示一次配對用 QR Code。用自己的手機掃描，讓 ChatGPT App 開啟連線流程；核對帳號與工作區，再完成所要求的驗證。每支手機與每台主機都要個別配對，不要分享 QR Code。

  3. 在手機上找到已配對的電腦

    開啟手機 ChatGPT App，依目前介面進入 Codex 或遠端連線功能，確認已配對的電腦出現在可選清單中。入口名稱與位置可能隨版本變動。

從手機發起任務、審批權限與檢視程式碼差異（Code Diff）

選取目標電腦後，你可以繼續進行既有的對話，也可以選擇專案來新增任務。發送要求後，手機會即時同步執行進度與回覆內容；而真正的檔案讀寫與編譯測試仍然是在那台電腦上進行。

  • 遠端權限核准：手機可檢視等待處理的核准要求並作出決定；通知與按鈕文案依手機系統、App 版本及通知設定而異。先看清具體動作與影響範圍。
  • 手機端檢查結果：可從手機追蹤任務進度與回覆；若目前介面提供程式碼差異（Code Diff），再逐項檢查變更與測試結果。重要變更仍建議回到桌面或 Git 專案完整審閱。
  • 需要時使用「幫我核准（Approve for me）」：這個模式會使用自動審查（Auto-review）。長任務可依風險選擇第 3 章介紹的核准模式；遠端收到核准要求時，仍要檢查具體動作與影響範圍。

手機上的遠端連線（Remote）、雲端任務（Cloud）與安全殼層（SSH）

若手機版顯示 Codex 分頁，可依帳號已開通的選項管理不同遠端環境。安全殼層（Secure Shell，SSH）是連線到另一台主機的方式，須先設定目標主機與存取權限：

環境類型運作方式電腦是否需開機？
本機遠端連線（Remote）連接家中或辦公室已配對的 Windows / Mac 桌面版，能使用哪些本機資料夾與工具仍由主機權限及核准規則決定。是（電腦須保持開機喚醒且執行桌面版 App）。
Codex 雲端任務（Cloud）針對已連結 GitHub 的儲存庫，在 OpenAI 託管的雲端隔離環境執行任務；能否發起 PR 依目前帳號、整合與權限而定。否（雲端任務不依賴你自己的桌面電腦保持開機）。
SSH 主機或 Work 雲端任務（Work Cloud）若帳號及工作區提供這些入口，可選擇已設定的遠端主機或雲端工作環境；各自的檔案與權限需另外確認。依所選主機或雲端環境而定；本機工作不會因電腦離線自動轉到雲端。

連線與安全最佳實踐

使用本機遠端連線（Remote）時，電腦必須保持開機連線、喚醒狀態，並持續執行桌面版應用程式。如果找不到入口或無法連線，請先將手機與電腦兩端更新至最新版本、核對帳號與工作區，並檢查電腦是否進入休眠。

若遠端任務還要操作 Windows 桌面程式（電腦操控，Computer use），工作階段需保持解鎖、連接網路，且目標應用程式可見；單純保持電腦開機不足以完成桌面操作。詳見 官方電腦操控文件。

請只連接自己信任的個人裝置。不再使用時，隨時可在電腦的「設定 → 連線」中撤銷配對；切勿將配對 QR Code、裝置資訊或核准畫面中的敏感內容公開分享。

手機只是操作入口：從手機連回自己的電腦，不會自行擴大那台電腦可用的檔案或工具權限。雲端任務（Cloud）則在另一個環境執行，能使用哪些儲存庫、網路連線與憑證，須檢查該雲端環境的設定；不要以本機的核准選單推定雲端權限。官方雲端環境說明
